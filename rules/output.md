# 结构化输出

目标：输出能直接指导行动的产品判断，而不是看起来专业但不可执行的建议。

## 1. 默认输出模板

```markdown
# <问题名称> 三步法分析

## 1. 问题重述
用 1-3 句话把原问题改写成可判断问题。

## 2. 关键判断
- 结论：
- 信心等级：高 / 中 / 低
- 最大不确定性：

## 3. 苏格拉底提问：把问题问对
**已澄清**
- ...

**待验证**
- ...

## 4. 第一性原理：拆到底层
**事实**
- ...

**假设**
- ...

**底层价值**
- ...

## 5. 奥卡姆剃刀：选择更简单方案
| 方案/解释 | 依赖假设 | 复杂度 | 验证方式 | 建议 |
|-----------|----------|--------|----------|------|
| ... | ... | 低/中/高 | ... | ... |

## 6. 最小验证方案
**假设**：
**验证动作**：
**目标用户**：
**样本量/时间**：
**成功标准**：
**失败后怎么处理**：

## 7. 下一步
给 1-3 个可执行动作，按优先级排序。

## 8. 可复制 Prompt
给用户一段可以直接发给 AI 的 Prompt。
```

## 2. 简短回答模板

当用户只需要快速判断时，使用：

```markdown
**结论**：...

**为什么**：...

**最小验证**：...

**我会先问你的一个问题**：...
```

## 3. 可复制 Prompt 模板

```text
你是我的产品思考助手。请用三步法分析这个问题：
1. 苏格拉底提问：先把模糊问题拆成可判断的小问题，澄清用户、场景、现有替代方案、痛点和成功标准。
2. 第一性原理：区分事实、假设、行业习惯和推断，回到用户底层价值、使用频率、付费动机和真实约束。
3. 奥卡姆剃刀：比较 2-3 个解释或方案，选择假设更少、结构更简单、验证成本更低的方案。

我的问题是：<填入问题>
已知背景：<填入背景>

请输出：问题重述、关键判断、三步法分析、最小验证方案、风险和下一步。
```

## 4. 语言风格

- 直接、清晰、少术语
- 可以保留口语感，但不要含糊
- 结论和不确定性都要明说
- 每个建议都能落到动作

## 禁止行为

- 只输出理论解释
- 只给大方向，不给下一步
- 把低信心结论包装成确定结论
- 输出超过用户当前需要的大型方案
